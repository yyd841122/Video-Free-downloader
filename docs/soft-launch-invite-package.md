## 1. 内测目标

本次 Soft Launch 内测旨在在 **小范围真实用户** 场景下验证 MVP 主链路是否稳定、文案是否清晰、问题是否可复现，为是否扩大内测人数、切换 Stripe Live、排期 ASR 等决策提供依据。

**重点验证：**

| 方向 | 期望结果 |
|------|----------|
| 解析与下载 | B 站 / 抖音 / X / mp4 主链路可用；720p 免费下载正常 |
| 会员与支付 | Stripe Test Mode 开通 VIP 后，1080p 与权益生效 |
| AI 总结 MVP | 有平台字幕或上传 SRT/VTT 时可生成摘要、思维导图、问答 |
| 体验与文案 | 权限提示、无字幕诊断、支付说明易懂，不产生误导 |
| 反馈质量 | 问题可描述、可复现，便于排 P0/P1 |

**不在本轮目标：** 公开推广、正式商用收费、无字幕自动转写、全平台 100% 成功率。

## 2. 当前可测功能

### 视频解析与下载

- 粘贴或输入链接 / 分享文案 →「解析视频」
- 「粘贴」按钮：从剪贴板填入并自动清洗 URL
- **Bilibili**：需 App 扫码登录后解析；支持长链参数清洗
- **抖音**：`v.douyin.com` 分享短链；地址栏 `jingxuan?modal_id=` 链接
- **X（Twitter）**：支持去除 `?s=20` 等 query
- **mp4 直链**：常见直链可解析下载
- **免费用户**：720p 及以下清晰度下载
- **会员用户**：1080p / 更高清晰度（视平台与源视频）、批量下载、下载历史
- **大文件 / 长视频**：进度文案「服务器处理中 xx%」；800MB+ 已验证
- **手机端**：封面显示已修复

### AI 总结 MVP（需登录）

- 解析后点击「AI 总结 Beta」
- **平台字幕**：检测到字幕时优先使用平台字幕
- **上传字幕**：支持 **SRT / VTT**（UTF-8、UTF-8 BOM、GBK、GB18030 等）
- 输出：摘要、字幕文本、思维导图、问答
- 无字幕 / 平台限制时：页面给出结构化诊断与上传引导

### 账号与会员

- 邮箱注册 / 登录
- 个人中心：订单、任务记录、权益配额
- `/pricing` 套餐页与会员开通
- Terms / Privacy / 版权说明：`/legal/*`

### 其他

- YouTube：部分链接可尝试（不保证成功；可选 cookies，见 `/help/youtube-cookies`）
- 客服联系：**support@cozyguidehub.com**

## 3. 当前限制

请在内测全程牢记以下限制，并向志愿者如实说明：

| 限制项 | 说明 |
|--------|------|
| **ASR 未开放** | 无字幕视频 **不能** 自动语音转文字；需上传 SRT/VTT 或换有字幕的视频 |
| **AI 总结非全覆盖** | 抖音 / B 站 / YouTube 部分视频因 cookies、平台验证或无字幕可能失败 |
| **支付为 Test Mode** | Stripe 测试环境，**非正式扣款**；正式收费开放前会另行公告 |
| **YouTube** | 不保证稳定；勿反复上传 cookies 期待必然成功 |
| **平台与清晰度** | 并非所有视频、所有清晰度均可下载 |
| **规模与 SLA** | 当前服务器 2C/4G，不适合大规模并发；无企业级 SLA 承诺 |
| **推广范围** | 仅限受邀小范围，请勿对外大规模传播链接 |

## 5. 测试支付说明（Stripe Test Mode）

当前生产环境使用 **Stripe Test Mode** 进行内测支付验证：

- 套餐页会提示：**Stripe Test Mode，用于内测验证，不代表正式扣款**
- 点击「立即开通」后跳转 **Stripe 测试收银台**（非本地 Mock 模拟页）
- 支付成功后：个人中心显示 VIP、订单状态为已支付，可测 1080p 等会员权益
- **不会** 对你的真实银行卡产生正式商用扣款

### Stripe 标准测试卡（仅 Test Mode 有效）

| 字段 | 填写 |
|------|------|
| 卡号 | `4242 4242 4242 4242` |
| 有效期 | 任意未来日期（如 `12/34`） |
| CVC | 任意 3 位（如 `123`） |
| 邮编 | 任意（如 `12345`） |

更多测试场景见 [stripe-test-mode-setup.md](./stripe-test-mode-setup.md)。

### 建议顺带验证（可选）

- 待支付订单 → 个人中心「继续支付」（resume checkout）
- 支付取消页 → 返回套餐或订单列表
- 支付成功后 → 1080p 下载是否解锁

## 6. 推荐测试流程

按以下顺序体验，约 **30–60 分钟** 可覆盖主链路（可按需跳过可选步骤）。

### 步骤 1：注册 / 登录

1. 打开 https://videodown.cozyguidehub.com  
2. 注册新账号或使用已有账号登录  
3. 确认首页、套餐页、登录页文案无「AI 即将开放」「模拟支付 MOCK」等误导表述  

### 步骤 2：解析视频

1. 准备一条 **B 站 / 抖音 / X** 链接（建议自备，可脱敏反馈）  
2. 粘贴到首页输入框 →「解析视频」  
3. B 站：按提示扫码登录后再解析  
4. 确认出现封面、标题、格式列表  

### 步骤 3：下载 720p（免费）

1. 选择 **720p 或更低** 清晰度  
2. 点击「立即下载」  
3. 观察「服务器处理中 xx%」→ 浏览器保存文件  
4. 记录：是否成功、耗时、是否有报错  

### 步骤 4：VIP 测试 1080p（需 Test Mode 支付）

1. 打开 https://videodown.cozyguidehub.com/pricing  
2. 确认页头有 **Stripe Test Mode** 说明  
3. 选择套餐 → Stripe 测试卡完成支付  
4. 返回首页解析同一或另一条视频 → 选择 **1080p**（若列表有）→ 下载  
5. 确认会员提示不再阻拦 1080p  

### 步骤 5：上传 SRT/VTT 做 AI 总结

1. 登录状态下解析一条视频（优先选 **有字幕** 或自备字幕文件的视频）  
2. 点击「AI 总结 Beta」  
3. **路径 A**：有平台字幕 → 直接等待摘要 / 思维导图 / 问答  
4. **路径 B**：无字幕 → 按页面提示上传 **SRT 或 VTT** → 再次生成总结  
5. 记录：是否成功、等待时间、错误提示是否易懂  

### 步骤 6：查看 Account 订单和任务记录

1. 打开 https://videodown.cozyguidehub.com/account  
2. **我的订单**：确认 Test Mode 支付订单为「已支付」；若有待支付可试「继续支付」  
3. **任务记录**：确认下载任务、AI 总结任务状态（进行中 / 已完成 / 失败）  
4. **我的权益**：确认 VIP 标识、清晰度与 AI 相关说明  

### 可选加分项

- 抖音 `v.douyin.com` 短链或 `modal_id` 地址栏链接  
- 手机浏览器访问同一流程  
- 大文件 / 长视频下载体验  
- 批量下载（VIP）

## 8. 不要承诺（对内测志愿者 & 对外口径）

协调人与志愿者在沟通或转发时，**请勿** 对外暗示或承诺以下内容：

1. **已正式收费** 或「现在付款就是正式商用扣款」  
2. **无字幕自动转文字（ASR）** 已上线或「很快就有」  
3. **所有平台、所有视频** 都能解析、下载、AI 总结  
4. **所有视频都有字幕**，或 AI 一定能成功  
5. **YouTube 稳定可用**，或上传 cookies 一定成功  
6. **7×24 稳定**、大并发、企业级 SLA  
7. **公开大规模推广** 时间表（除非团队另行公告）  
8. 页面上 **未写明** 的会员权益或功能  

**可以如实说明：**

- 当前为 **Soft Launch 内测**，核心能力是解析、下载、AI 总结 MVP  
- 支付为 **Stripe Test Mode**，正式 Live 收费前会公告  
- 无字幕时请 **上传 SRT/VTT**，自动转写暂未开放
