## 6. 决策规则

### 可以扩大到 5–10 人的条件

满足 **多数** 以下条件时可考虑扩大受控 Beta：

- [ ] 至少 **1–3 人** 明确愿意付费或 **已付费**
- [ ] 人工开通流程 **无严重错误**（dry-run → confirm → Account 权益一致）
- [ ] 用户能理解 **Test Mode** 与 **人工收款** 的区别
- [ ] 无未解决的 **P0** 阻塞问题
- [ ] 至少有人 **成功完成下载或 AI 总结**

### 不应扩大的条件

出现以下情况时 **暂停扩大**，优先修文案 / 流程 / 主链路：

- [ ] 用户普遍 **不理解** 付款方式（误以为站内已正式扣款）
- [ ] 用户普遍 **不清楚** 产品价值或权益边界
- [ ] 下载 **主流程频繁失败**
- [ ] VIP 权益在 Account / 实际配额 **显示混乱**
- [ ] 出现 **支付或退款争议** 且未闭环
