## 1. 项目一句话

**SaveAny**：万能视频下载 + 会员付费 + AI 视频总结（字幕/导图/问答）。技术栈：Vue 3 + FastAPI + yt-dlp + SQLite + Stripe。

## 3. 已具备能力（对照代码）

### 3.1 用户侧

- 粘贴链接解析，选清晰度 **服务端下载**（自动触发浏览器保存）
- **批量下载**（登录 + 会员；最多 3 并发）
- **AI 总结**：摘要、字幕列表、思维导图、多轮问答
- 无平台字幕：提示 + **上传 SRT/VTT**；或开启 **ASR（Whisper）** 自动转写
- **个人中心**：权益配额、订单、任务历史（再下载 / 查看总结）
- **套餐购买**：Mock 或 Stripe Checkout

### 3.2 后端要点

| 能力 | 位置/说明 |
|------|-----------|
| 任务状态 | 内存 `task_store`（**单 worker** 部署） |
| 持久化 | SQLite `backend/data/app.db` |
| 清理 | `cleanup_service` 按 `.saveany-meta.json` 保留时长删目录 |
| 直链 API | `/api/video/direct`、`/api/redirect`、`/api/proxy`（**前端未接**） |
| Webhook | `POST /api/billing/webhook`（非 `/api/payment/webhook`） |

### 3.3 环境变量速查

见 `backend/.env.example` 与 [生产部署清单.md](./生产部署清单.md)。上线必改：`MOCK_PAYMENT`、`JWT_SECRET`、`FRONTEND_URL`、`ALLOWED_ORIGINS`、Stripe Live。

## 5. 运维与架构注意

1. **任务在进程内存**：`uvicorn --workers 1`；重启丢进行中任务列表（磁盘文件可能仍在）。
2. **磁盘**：`backend/downloads/` 为中转；会员批量 + 长视频需关注容量（清单中有粗算）。
3. **Whisper**：`ASR_ENABLED=false` 可先上线；无字幕多时再 Docker 同机部署。
4. **Cloudflare 橙色云**：大文件下载可能不稳，必要时 `api` 子域名灰色云 + 源站 HTTPS。
5. **批量并发**：会员满 3 个活跃任务时，新批量会报「最多同时进行 3 个下载」——属预期。

## 6. 推荐迭代顺序（买服务器之后）

```text
① 腾讯云香港轻量 + Ubuntu + SSH
② Cloudflare A 记录 → VPS IP
③ 部署后端 + 前端 dist + Nginx（ASR_ENABLED=false）
④ Stripe 测试模式全流程 → 再 Live
⑤ 自测：单条下载、批量、AI（有字幕 / 无字幕各 1）
⑥ 稳定后可选：Whisper、直链 UI、文案去掉「优先队列」、关生产 Swagger
```
