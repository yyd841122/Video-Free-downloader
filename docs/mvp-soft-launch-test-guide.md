## 当前可测功能

### 解析与下载

- 粘贴或输入视频链接 / 分享文案，点击「解析视频」
- 使用「粘贴」按钮从剪贴板一键填入并清洗 URL
- B 站：扫码登录后解析；支持带 `spm` / `vd_source` 的长链清洗
- 抖音：分享文案提取 `v.douyin.com`；地址栏 `jingxuan?modal_id=`（normalize 为 `iesdouyin.com/share/video/{id}/`）
- X：支持去掉 `?s=20` 等 query
- 免费用户：720p 及以下清晰度下载
- 会员用户：1080p / 更高清晰度（视平台与源视频）、批量下载、下载历史

### AI 总结 MVP

- **已开放**：解析视频后点击「AI 总结 Beta」发起总结（需登录）
- **平台字幕**：若检测到字幕，优先使用平台字幕生成摘要、思维导图、问答
- **上传字幕**：无平台字幕时可上传 **SRT / VTT**（支持 UTF-8、UTF-8 BOM、GBK、GB18030 等常见编码）
- **暂未开放**：无字幕视频的 **自动语音转文字（ASR）** — 请勿期待 Whisper 本机转写
- **可能失败**：抖音 / B 站 / YouTube 部分视频因 cookies、平台验证或无字幕而无法直接总结 — 页面会给出友好提示，可改上传字幕

详见：[ai-summary-mvp-validation.md](./ai-summary-mvp-validation.md)、[ai-summary-test-samples.md](./ai-summary-test-samples.md)

### 账号与支付（Stripe Test Mode）

- 注册 / 登录 / 个人中心
- `/pricing` 套餐页 → Stripe **Test Mode** Checkout（内测支付验证）
- **重要**：当前为 Stripe 测试环境，用于验证会员开通、1080p、resume checkout、取消流程；**不代表正式对外收费**。内测用户请使用测试卡流程，不要理解为真实扣款。
- 支付完成后 account 显示 VIP 与订单记录
- 本地开发若启用 `MOCK_PAYMENT` 才会走 Mock 收银页（生产通常为 Stripe Test Mode）

### 交互与体验

- 输入框右侧 X：清空输入与旧解析状态
- 未登录 / 会员权限：就近提示
- 下载中：「服务器处理中 xx%」文案
- AI 无字幕 / cookies 错误：结构化诊断 + 上传字幕引导

### 页面与路由

以下页面应可正常访问（HTTP 200，无空白页）：

- `/` 首页
- `/pricing` 套餐
- `/login` `/register` 登录注册
- `/account` 个人中心（需登录）
- `/legal/privacy` `/legal/terms` `/legal/copyright`
- `/help/youtube-cookies`

## 当前不可承诺内容

对内测用户及对外宣传 **不要承诺** 以下内容：

1. **YouTube 稳定可用**，或「上传 cookies 一定成功」
2. **所有视频都能 AI 总结**（尤其无字幕、需 cookies 的抖音/B 站/YouTube）
3. **无字幕自动转文字（ASR）** 已上线
4. **Stripe Test Mode 等同于正式商用收款** 或「已全面正式收费」
5. **所有平台、所有清晰度、所有视频** 均可下载
6. **7×24 稳定**、大并发、企业级 SLA
7. **公开大规模推广** 或对外正式发布时间表（除非另行公告）
8. 任何 **未在页面上明确写出** 的会员权益

**可以如实说明：**

- 当前是 **内测 / Soft Launch**，以 **解析 + 下载 + AI 总结 MVP** 为主
- AI：上传 SRT/VTT 或有平台字幕时可总结；无字幕自动转写 **暂未开放**
- 支付：**Stripe Test Mode** 内测验证；正式收费开放前会公告
- 问题反馈：**support@cozyguidehub.com**

## 测试任务清单

### A. 基础访问（每人约 5 分钟）

- [ ] 打开首页，确认 hero 完整、无空白页
- [ ] 访问 `/pricing`、`/login`、`/register`、`/account`（未登录会跳转登录）
- [ ] 确认套餐页有 **Stripe Test Mode / 内测支付** 说明（非「模拟支付 MOCK」误导文案）
- [ ] 首页向下滚动后 **F5 刷新**，应回到页面顶部

### B. 链接解析（核心）

- [ ] **B 站** 带 `spm`/`vd_source` 长链 → 粘贴或点「粘贴」→ 扫码登录 → 解析成功
- [ ] **抖音** 整段分享文案 → `v.douyin.com` 短链 → 解析成功
- [ ] **抖音** 地址栏 `jingxuan?modal_id=` → normalize → 解析 + 下载成功
- [ ] **X** 带 `?s=20` 链接 → query 被去掉 → 解析成功
- [ ] **mp4 直链**（如有）→ 可解析 / 下载

### C. 下载（免费账号）

- [ ] 选择 **720p 或更低** → 立即下载 → 「服务器处理中 xx%」→ 浏览器保存
- [ ] 点击 **1080p 会员项** → 格式列表附近出现会员提示
- [ ] 确认 **720p 不再** 出现「3006p 会员专享」类错误
- [ ] （可选）大文件 / 长视频下载完成或失败文案合理

### D. AI 总结 MVP（建议至少 1 人深度测）

- [ ] **有平台字幕** 的视频 → 登录 → AI 总结 → 出现摘要 / 思维导图 / 问答
- [ ] **无字幕** 视频 → 提示可上传 SRT/VTT；**不应** 长时间假 loading 或 Raw Douyin cookies 报错
- [ ] 上传 **UTF-8 / GBK** 等编码的 SRT/VTT → 总结成功
- [ ] 未登录点 AI → 就近提示登录（非「即将开放」）

### E. Stripe Test Mode 支付（可选，建议 1 人）

- [ ] 注册 → 登录 → `/pricing` 确认 **Test Mode / 非正式扣款** 文案
- [ ] 完成 Stripe 测试支付 → `/account` 显示 VIP + 已支付订单
- [ ] **继续支付** / 取消订单流程可测
- [ ] VIP 后 1080p 下载闭环

### F. 已知不测 / 不测深

- [ ] YouTube：随手试 1 条即可
- [ ] ASR / 无字幕自动转写：本轮 **不测**（未开放）
- [ ] 公开传播、大规模并发、SEO/推广：本轮 **不做**

## Bug 分级规则

| 级别 | 定义 | 示例 | 内测期间处理 |
|------|------|------|--------------|
| **P0** | 核心链路完全不可用；数据/安全风险 | 首页白屏；解析/下载全失败；误正式扣款；泄露他人数据 | **立即停测 + 24h 内修** |
| **P1** | 主平台单链路严重受阻；误导性付费/权限 | B 站/抖音/X 稳定无法下载；免费 720p 仍被拦；文案暗示已正式收费 | **本轮回修优先** |
| **P2** | 体验差但不阻断主流程 | 提示位置不对、文案歧义、YouTube 失败、AI 某平台偶发失败 | 记录，内测后批次修 |
| **P3** | cosmetic / 优化 | 间距、翻译、历史样式 | backlog |

**内测判责原则：**

- YouTube 失败 → 默认 **P2**
- AI 无字幕且未上传字幕 → **非 bug**（预期，引导上传）
- ASR 用户期待自动转写 → **非 bug**（未开放，记录需求）
- Stripe Test 支付未到账 VIP → **P1**
- 私密视频 / 平台下架 / 个人网络 → **环境原因**，非产品 bug

## P1_AFTER_TEST

内测结束后 **优先处理**：

1. 确认 **720p 免费下载** 无回归
2. 确认 **AI 总结 MVP** 主路径（平台字幕 + 上传 SRT/VTT）稳定
3. 确认 **Stripe Test Mode → VIP → 1080p** 闭环
4. 收集 **P1 新 bug** 与 **Top 5 文案困惑点**
5. 决定是否扩大内测人数 / 切换 Stripe Live / 排期 ASR
