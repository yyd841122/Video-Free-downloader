## 当前可测功能

### 解析与下载

- 粘贴或输入视频链接 / 分享文案，点击「解析视频」
- 使用「粘贴」按钮从剪贴板一键填入并清洗 URL
- B 站：扫码登录后解析；支持带 `spm` / `vd_source` 的长链清洗
- 抖音：支持整段分享文案提取 `v.douyin.com` 短链
- X：支持去掉 `?s=20` 等 query
- 免费用户：720p 及以下清晰度下载
- 会员用户（Mock 开通）：1080p / 更高清晰度（视平台与源视频）、批量下载

### 账号与支付（Mock）

- 注册 / 登录 / 个人中心
- `/pricing` 套餐页与 Mock 模拟支付（不会真实扣款）
- 支付完成后 account 显示 VIP 与 MOCK 订单记录

### 交互与体验

- 输入框右侧 X：清空输入与旧解析状态
- 未登录 / 会员权限：就近提示（非仅顶部报错）
- 下载中：「服务器处理中 xx%」文案
- AI 总结 Beta：点击显示接入中提示，不发起 API

### 页面与路由

以下页面应可正常访问（HTTP 200，无空白页）：

- `/` 首页
- `/pricing` 套餐
- `/login` `/register` 登录注册
- `/account` 个人中心（需登录）
- `/legal/privacy` `/legal/terms` `/legal/copyright`
- `/help/youtube-cookies`

## 当前不可承诺内容

对内测用户及对外宣传 **不要承诺** 以下内容：

1. **YouTube 稳定可用**，或「上传 cookies 一定成功」
2. **AI 总结已完整可用**、每日次数（如 3 次/50 次）、思维导图 / 问答已上线
3. **Mock 支付等同于真实 Stripe 商用收款体验**
4. **所有平台、所有清晰度、所有视频** 均可下载
5. **7×24 稳定**、大并发、企业级 SLA
6. **公开大规模推广** 或对外正式发布时间表（除非另行公告）
7. **ASR 语音转写** 在无字幕视频上自动生成总结
8. 任何 **未在页面上明确写出** 的会员权益

**可以如实说明：**

- 当前是 **内测 / 测试版**，以 **解析 + 下载** 为主
- B 站需扫码；免费 720p；会员更高清 + 批量（Mock 环境）
- AI 与完整支付将在后续版本开放

## 测试任务清单

### A. 基础访问（每人约 5 分钟）

- [ ] 打开首页，确认 hero 完整、无空白页
- [ ] 访问 `/pricing`、`/login`、`/register`、`/account`（未登录会跳转登录）

### B. 链接解析（核心）

- [ ] **B 站** 带 `spm`/`vd_source` 长链 → 粘贴或点「粘贴」→ 清洗为干净 BV 链接 → 扫码登录 → 解析成功

- [ ] 选择 **720p 或更低** → 立即下载 → 按钮显示「服务器处理中 xx%」→ 完成后浏览器弹出保存

## Bug 分级规则

| 级别 | 定义 | 示例 | 内测期间处理 |
|------|------|------|--------------|
| **P0** | 核心链路完全不可用；数据/安全风险 | 首页白屏；解析/下载全失败；误扣款；泄露他人数据 | **立即停测通知 + 24h 内修** |
| **P1** | 主平台单链路严重受阻；误导性付费/权限 | B 站/抖音/X 稳定复现无法下载；免费 720p 仍被拦；Mock 文案像真扣款 | **本轮回修优先** |
| **P2** | 体验差但不阻断主流程 | 提示位置不对、文案歧义、偶发失败、YouTube 失败 | 记录，内测后批次修 |
| **P3** |  cosmetic / 优化 | 间距、英文翻译、历史记录样式 | backlog |

**内测判责原则：**

- YouTube 失败 → 默认 **P2**（已知限制）
- AI 总结无结果 → **非 bug**（Beta 预期）
- MOCK 支付未到账 VIP → **P1**（流程问题）
- 仅自己网络/平台下架/私密视频 → **不记为产品 bug**，标注环境原因
