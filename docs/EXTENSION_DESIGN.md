# SaveAny Browser Extension Design

## Goal

The browser extension is an enhancement path for platforms where a pure server-side website cannot reliably parse high-quality streams, such as Bilibili HD, iQIYI, Tencent Video, Douyin, and other dynamic playback pages.

The extension runs inside the user's own browser, so it can observe the real playback requests generated by the page after the user opens and plays the video.

## MVP Scope

Current implementation:

- Chrome/Edge Manifest V3 extension in `browser-extension/`.
- User manually starts capture from the extension popup.
- Extension records likely media requests: `m3u8`, `mpd`, `m4s`, `ts`, `mp4`, `webm`, `flv`, `mov`.
- Safe headers are captured by default:
  - `User-Agent`
  - `Referer`
  - `Origin`
  - `Range`
  - `Accept`
  - `Accept-Language`
- Sensitive headers are disabled by default:
  - `Cookie`
  - `Authorization`
- Captured data can be sent to local FastAPI:
  - `POST /api/extension/captures`
  - `GET /api/extension/captures/{capture_id}`

## Why Manual Capture

Websites cannot silently install extensions or silently read browser cookies. The user must install the extension themselves and explicitly choose when to capture a page.

This protects the user from hidden collection of login state and keeps the product boundary clear.

## Security Boundary

Default mode does not capture cookies. This is enough for many public media URLs.

If a platform requires login state, the product should only enable sensitive-header capture after clear user confirmation. For public web service deployment, the safer long-term path is:

```text
Website UI
-> Browser extension captures playback context
-> Local helper downloads and merges on the user's machine
-> Cookies never leave the user's device
```

## Next Development Steps

1. Add a frontend page to display extension capture results.
2. Convert captured `m3u8` / `mpd` / direct media URLs into downloadable tasks.
3. Add local-helper download mode for large files, ffmpeg merge, and cookie-safe downloads.
4. Add platform-specific parsers for Bilibili DASH and iQIYI HLS/DASH captures.
5. Add validation to avoid saving HTML error pages as fake video files.

## Limitations

- The extension cannot bypass VIP permissions, DRM, regional restrictions, or platform access rules.
- DRM-encrypted streams are out of scope.
- Captured URLs may expire quickly and should be downloaded immediately.
- Chrome Web Store / Edge Add-ons publication is required for normal users; websites cannot auto-install extensions.
